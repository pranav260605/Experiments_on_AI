Original:
A LEFT JOIN returns all rows from the left table and only the matching rows from the right table. When no match is found, the result is NULL for columns from the right table. This is fundamentally different from an INNER JOIN, which returns only rows where a match exists in both tables.
Claude-Sonnet 4.6:
A LEFT JOIN gives you every row from the left table, no matter what. For rows where the right table has matching data, that data is included. Where there's no match, the right table's columns just show NULL. This stands in contrast to an INNER JOIN, which is more selective — it only returns rows that have corresponding matches on both sides.
